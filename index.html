Structural Manual

Bio 2 Core Concepts & Reference Guide

1. Double Helix Geometry

B-DNA forms a right-handed double helix with approximately 10.5 base pairs per helical turn and a rise of 3.4 Å per base pair. The pitch per turn is 34 Å with an overall diameter of ~20 Å (2 nm).

2. Hydrogen Bonding Rules

Complementary base pairing maintains constant helical width:

  • Adenine = Thymine (2 H-Bonds)
  • Cytosine ≡ Guanine (3 H-Bonds)

3. Antiparallel Directionality

The two sugar-phosphate backbones run in opposite directions. One strand runs 5' to 3' (derived from the 5th and 3rd carbons of deoxyribose sugar ring), while the complementary strand runs 3' to 5'.

4. Major & Minor Grooves

Due to the offset glycosidic bonds between base pairs and sugars, the backbones are unevenly spaced, creating alternating Major Grooves (~22 Å wide) and Minor Grooves (~12 Å wide). Transcription factors interact primarily within the major groove.

Technical Overview & Pedagogical Architecture

Project Overview

Bio 2 Interactive Capstone Assessment System

Engineered to replace static 2D textbook diagrams with an interactive, web-based 3D spatial simulation. Built using client-side WebGL (Three.js) to provide immediate tactile feedback on molecular symmetry, stoichiometry, and thermodynamic stability (Melting Temp Tm calculations).

Tech Stack & Algorithms

• Renderer: Three.js WebGL Engine
• Math: Parametric double-helix curve equations ($x = r \cos \theta$, $y = h \theta$, $z = r \sin \theta$)
• Interactions: Raycasting object picker for nitrogenous base selection.
• Thermodynamics: Nearest-neighbor Tm estimation logic based on GC content ratio.

Learning Outcomes

• Mastery of Chargaff's rules of base pairing stoichiometry.
• Spatial differentiation between purine and pyrimidine molecular geometry.
• Visualization of 5' to 3' antiparallel orientation in DNA replication readiness.
